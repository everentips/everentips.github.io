How to Install

About 5 minutes. Everything you need is free. Each download also has this guide in README - Start Here.txt.

Requirements

REAPER 7 or newer
ReaPack — REAPER's package manager
ReaImGui 0.9+ — draws the windows (required)
SWS Extension — preview, drag & drop (required)
js_ReaScriptAPI — drag & drop, alignment (recommended)
  1. 1

    Install ReaPack and SWS

    In REAPER, choose Options > Show REAPER resource path. Download ReaPack from reapack.com and SWS from sws-extension.org, put them in the UserPlugins folder there, then restart REAPER.

  2. 2

    Install ReaImGui and js_ReaScriptAPI

    Extensions > ReaPack > Browse packages. Type imgui and install "ReaImGui: ReaScript binding for Dear ImGui" (category API). Then search js_ReaScriptAPI and install it. Click Apply and restart REAPER.

    Tip: it is ReaImGui with a capital i — typing imgui avoids the mix-up.

  3. 3

    Add the scripts

    Unzip each download and copy its Scripts/Everentips folder into REAPER's Scripts folder — several tools simply share one Everentips folder. Open the Action List > New action > Load ReaScript and load the tool (for example Everentips - Chord Engine.lua). Give it a shortcut or toolbar button.

    No need to load the Beat Engine Linker — Beat Engine sets it up by itself.

  4. 4

    Install the Kakada theme (optional)

    Unzip the Kakada download, then load and run Install Kakada.lua the same way and restart REAPER. It installs the theme and its toolbar icons — nothing else changes.

FAQ

Is it really free?

Yes. Enter $0 at checkout and download. If the tools save you time, paying what you want helps fund updates and new tools.

Is it safe to run?

The scripts are plain, readable .lua files — nothing is hidden or compiled, so you (or anyone) can check exactly what they do. They only work inside your REAPER projects.

Does it work on Mac and Windows?

The tools are built for REAPER 7 and use cross-platform extensions (ReaImGui, SWS, js_ReaScriptAPI). They are developed and tested on macOS; please report anything that behaves differently on Windows.

A script says ReaImGui is missing — what now?

Open Extensions > ReaPack > Browse packages, type imgui, right-click "ReaImGui: ReaScript binding for Dear ImGui" and choose Install (or Reinstall if it is already there). Click Apply and restart REAPER.

Can I use it in commercial music?

Yes. Use the tools for any music, personal or commercial — no credit needed. What you may not do is re-share, re-upload or sell the scripts; please link people to this page instead.

How do I get updates?

New versions are posted here. Download again with the same link and replace the files in your Scripts/Everentips folder — your settings are kept.

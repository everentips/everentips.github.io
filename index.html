How to Install & Run

Simple steps to get your downloaded .luac script running in REAPER.

1

Download the Package

Grab the .zip file from the checkout page (enter $0 for free or any amount to support development).

2

Open REAPER Resource Path

In REAPER, go to Options > Show REAPER resource path in explorer/finder.

3

Load Into Action List

Place the .luac file inside your Scripts/ folder, open REAPER's Action List, and click New action > Load ReaScript.
